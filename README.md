
#AI 패션 스타일링 프로그렘

고객 선호 설문 + AI 스타일링 + 트렌드 반영 DP
## 프로젝트 소개
고객선호 설문조사를 기반으로 의류 브랜드나 스타일리스트가 특정 콘셉이나 트렌드에 맞춰 준비한 옷을 AI가 스타일링 후, 사진이나 영상으로 담아 소비자에게 제공하는 방식입니다.
GPT 같은 생성형 AI 기반으로 가상으로 DP 가 가능하여 쇼핑할때 사용되는 시간과 체력을 아껴 줄 뿐만 아니라 . 
한번도 시도해보지않았던 스타일에 옷도 가상 DP로 시도해 봄으롯서 여러 방면의 스타일링을 도전해 볼 수 있습니다.
____
## 프로젝트 목적
트렌드의 변화가 급변하는 요즘 또 쇼핑하러 갈 시간이 없는 사람들을 위해 자신의 신체스팩과 비슷한 AI를 사용하여 실착해보지 않고도 자신에게 맞는 스타일링을 할 수 있다.

____

## 프로젝트 내 기능

✔️   비회원/로그아웃 
- AI가 스타일링한 옷 사진/영상을 가상 마네킹에 소개
- 고객들이 직접 리뷰에 올린 피드백 열람 가능
- 회원가입 유도
- sns 계정연결 링크

  회원가입
- 이메일 ,비밀번호 입력, 비밀번호 재 입력, 인증
- 이메일  인증번호 입력시 검증, 실패시 재 전송
  sns 계정연결 링크
- 관리자의 sns (카카오톡, 인스타그램 ) 링크로 이동해 간단한 상담. 챗, 문의, 등


✔️  로그인 한 회원
- 모든 회원정보는 Django 기반 + a 로 보안한다.(개인정보유출위험)

| 순위  | 구성 요소                   | 설명                         |
| --- | ----------------------- | -------------------------- |
| ①   | `HTTPS + SSL + HSTS`    | 트래픽 암호화 필수 (Let’s Encrypt) |
| ②   | `django-environ + .env` | 민감 정보 유출 방지                |
| ③   | `SimpleJWT or Axes`     | 인증 보안 강화 및 비정상 로그인 차단      |
- 로그인 한 회원 / 회원가입 시 간단한 신체치수와 선호하는 스타일 , 시도해보고 싶은 스타일 등 목록이 있는 설문조사 앱 만들기. 
- 
- 접속한 날의 게절 , 날짜(년)의 트렌드에 맞춰 신체치수와 비슷한 AI 마네킹에 DP

| 날짜확인  | openweather API key 또는 data time 모듈      |
| ----- | ---------------------------------------- |
| 트렌드분석 | 패션트렌드 관련 사이트나 sns에서 웹 크롤링 or 이미지/텍스트로 수집 |
| 가상마네킹 | DALL-E 등으로 이미지생성                         |
| 결과 표시 | 사용자의 신체정보 기반 스타일링 이미지/영상 제시              |

✔️ 설문조사 베이스로한 키워드에 맞는 옷 데이터 가져오기(키워드 정리)
- 설문에서 수집한 키워드( 스트릿, 케주얼 ) 기반
- 데이터 베이스 or 외부 API에서 의류 데이터를 불러와 추천리스트 제공
